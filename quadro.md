# Aula 1

## Conceitos fundamentais

- **Complexidade** = esforço computacional
- **Ordenação** = quantidade de comparações e quantidade de trocas

## Operações básicas

- **C** - Create
- **R** - Retrieve
- **U** - Update
- **D** - Delete

> Para usar uma árvore, é necessário que os dados estejam **ordenados**.

## Algoritmos de ordenação

- **Bubble Sort**: o maior elemento "sobe" como uma bolha até o final da iteração. (pouco utilizado)
- **Merge Sort**
- **Quick Sort**
