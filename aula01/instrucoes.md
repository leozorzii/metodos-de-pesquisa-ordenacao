# Instruções do desafio

## 1. Criar uma classe com métodos para:

1. Ler dados de um arquivo, onde os valores estão inseridos um abaixo do outro, e popular uma lista.
2. Exibir a lista populada.

## 2. Criar um programa principal com um menu:

1. Carregar arquivo
2. Mostrar dados carregados
3. Encerrar

> O programa deve solicitar a opção escolhida pelo usuário.

## 3. Projeto de software

- **MVC (Model-View-Controller)**
  - **Model**: classes de dados
  - **Controller**: classes de regras de negócio
  - **View**: classe de interação com o usuário
